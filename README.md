# Advanced-IoT-Systems-and-Design

This repo contains course materials including lecture slides, lecture videos, assignments, labs, and end-of-semester projects.

Textbooks:
1.	Gian Marco Iodice: TinyML Cookbook (2nd ed.), Packt, 2023.
2.	Simon Monk: Programming Arduino: Getting Started with Sketches (3rd ed.), McGraw Hill, 2022.
3.	Perry Lea: IoT and Edge Computing for Architects (2nd ed.), Packt, 2020.

Supplementary texts and standards
1.	Pete Warden and Daniel Situnayake: TinyML: Machine Learning with TensorFlow Lite on Arduino and Ultra-Low-Power Microcontrollers, O'Reilly, 2019.
2.	David Hanes et al.: IoT Fundamentals: Networking Technologies, Protocols, and Use Cases for the Internet of Things, Cisco Press, 2017.
3.	NIST SP 800-232 (2025): Ascon-Based Lightweight Cryptography Standards for Constrained Devices.
4.	P. Warden (2018): Speech Commands: A Dataset for Limited-Vocabulary Speech Recognition, arXiv:1804.03209.
